# 完整制卡规则

本规则用于指导 Agent 生成内容。问答与单空填空可由本仓库脚本直接导出；选择题可写为 Basic，图片遮挡仅为设计指导，本版尚无原生遮挡导出器。

## 一、制卡目标

将提供的 PDF、PPT 或课堂笔记转化为适合主动回忆和长期复习的 Anki 卡片。卡片应帮助学习者记住、理解和运用知识；每张卡都应有明确的学习目标、可判断的答案和可追溯的来源。

## 二、理解资料后再制卡

1. 先理解章节结构、学习目标、核心概念及其关系，再开始生成卡片。
2. 阅读正文时，同时检查标题、图表、公式、脚注、例外和限制条件。
3. 多栏排版、表格、流程图和扫描页需要结合图像理解，不能仅依赖文字抽取顺序。
4. 长资料可以分章节处理，但最终必须跨章节检查重复、矛盾和遗漏。
5. 只处理部分资料时，说明覆盖的章节或页码。

## 三、知识点筛选

优先为以下内容制卡：

- **定义**：概念是什么，如何识别。
- **条件**：结论、行为或规则何时成立。
- **机制**：为什么发生，通过什么过程发生。
- **对比**：相近概念在一个关键维度上的区别。
- **流程**：步骤、顺序、前提和关键节点。
- **公式**：表达式、变量含义、单位和适用条件。
- **应用**：根据资料中的规则判断一个具体情境。
- **边界与例外**：什么情况下不成立，容易出现什么误解。
- **关键事实**：有记忆价值的名称、数字、日期和分类。

目录、装饰文字、重复说明和不影响理解的细节通常不单独制卡。案例优先提炼其说明的规律；只有案例细节本身需要记忆时，才单独考查。不能仅因某句话容易改成问题，就为它生成卡片。

## 四、每张卡只考一个目标

每张卡对应一个可以独立判断掌握程度的回忆目标。例如，“校验码长度是多少？它有什么作用？”拆为“该系统的校验码长度是多少？”和“该系统的校验码用于检测什么问题？”。

1. 定义、用途、原因、数字和例外如果可以独立掌握，通常分别制卡。
2. 对比卡可以包含两个对象，但只比较一个明确维度。
3. 简短且必须整体记忆的流程可以放在一张卡中。
4. 长流程拆成整体顺序、关键步骤和触发条件。
5. 如果可能答对前半部分、答错后半部分，应检查是否需要拆卡。
6. 不要过度拆分到失去语境，或产生没有独立学习价值的碎片卡。

## 五、题干编写

1. 明确考查对象和必要条件；脱离原页后仍能独立理解。
2. 避免“它”“上述”“这个概念”等依赖上下文的指代。
3. 答案范围明确，避免“介绍一下”“谈谈理解”等宽泛问法。
4. 优先主动回忆问题，例如是什么、为什么、什么条件下、如何区分、下一步是什么。
5. 尽量避免只回答是/否或正确/错误；改问成立条件、原因或正确结论。
6. 题干不能直接包含目标答案，也不能用明显提示让人无需理解就猜中。
7. 删除无关背景，但保留决定答案的条件。
8. 同一问题如果有多个合理答案，应补充范围或改写。

## 六、答案编写

1. 标准答案简洁、明确，便于学习者判断自己是否答对。
2. 保留必要的关键词、条件、单位和限定。
3. 不将整段原文直接粘贴为答案，不塞入多个独立考点。
4. 帮助理解的背景、推导、机制、案例和助记放在 explanation 中。
5. 允许多种等价表述时，不把一种措辞误当作唯一答案。
6. 不把“可能”“通常”“在特定条件下”改成“一定”“全部”“任何情况下”。

## 七、卡型选择

### 问答卡

适合定义、机制、条件、比较、流程和情境应用。题目应引导学习者主动生成答案。默认不自动生成反向卡；只有反向关系具有独立学习价值时才生成。

### 填空卡

适合明确语境中的术语、数字、名称或公式。

1. 默认每张卡只挖一个目标，保留足够上下文，使答案明确。
2. 不挖空整句话或整段文字。
3. 不通过同义词、语法或相邻文字泄漏答案。
4. 多个独立目标拆成多张卡。
5. 使用 `{{c1::答案}}`；本版每条 note 只出现一次 c1。
6. 提示仅用于消除歧义，不能直接给出答案。

### 选择题

在用户需要识别、辨析或考试练习时使用。

1. 题干有明确目标；默认一个正确答案，多选必须明确标注。
2. 干扰项应合理，并与常见误解相关。
3. 避免选项重叠、答案歧义和明显凑数的选项。
4. 不用选项长度、语法或固定位置暗示答案。
5. 给出正确选项及依据，必要时解释其他选项不成立的原因。
6. 干扰项可以表达有意设计的错误命题，但答案解释必须指出错误；不能把虚构数据冒充来源事实。

### 图片辅助或遮挡卡

适合结构识别、位置、图示关系和流程节点。

1. 图片清晰，保留必要的方向、比例、图例和上下文。
2. 每张卡聚焦一个识别目标。
3. 正面图片不能通过未遮挡标签泄漏答案。
4. 普通整页截图可以放背面帮助回看，不能冒充图片遮挡卡。
5. 无法可靠遮挡或辨认时，改为文字问答或标为待核对。
6. 本仓库当前只导出图片辅助卡；用户明确需要原生遮挡时说明能力边界。

## 八、不同内容的特殊规则

**数字与日期**：保留单位、时间范围、统计口径和成立条件。区分示例值、测量值、平均值、上限和最大值，不把其中一种替代另一种。

**公式**：核对符号、上下标、正负号、括号和单位。需要时分别考公式、变量含义和适用条件。资料未定义的符号不能自行补定义。

**流程**：区分步骤顺序、进入条件、完成条件和失败分支，不能将中间步骤误写为最终完成状态。

**分类与列表**：短且需要整体掌握的列表可以整体考；长列表按类别、层级或辨别特征拆分，避免一次背诵大量无关联条目。

**表格与图表**：核对行列、坐标轴、单位、图例、样本范围和脚注；不把相邻列配错，不把相关关系改成因果关系。

**规则性材料**：法律、医学等条件密集的材料，保留适用对象、前提、例外、版本和时间范围，避免无条件的绝对结论。

## 九、来源与事实约束

1. 每张卡都有支持答案的来源。
2. PDF 使用文件名及从 1 开始的物理页码；印刷页号可补充，但不能混淆。
3. 综合多页时，标注所有必要来源页。
4. 保留支持答案的短引文或清晰的图表定位，便于复核。
5. 引用了某页，不代表该页一定支持答案，仍需检查对应内容。
6. 默认只使用所提供资料中的事实。
7. 自行情境只能应用资料已给出的规则；如果加入假设，必须明确标为假设，不能伪装成来源事实。
8. 外部补充与原文明确区分；与原文冲突时单列说明。
9. 看不清、缺失或有矛盾的内容标为待核对，不凭常识补齐。

## 十、去重与覆盖

1. 同一考点跨页重复时，原则上合并，并保留必要来源。
2. 措辞不同但目标相同，也应检查重复。
3. 同一概念的不同角度可分别保留，但须有独立学习价值。
4. 建立知识点清单：included 已有对应卡；excluded 不制卡并说明原因；blocked 资料不足或存在问题，并说明解决方式。
5. 不通过反复改写同一问题增加数量。
6. 用户要求的数量超过资料可支持的有效考点时，说明不足，不能凑卡。
7. 没有历年题或其他证据时，不能声称某点“考试高频”。

## 十一、最终逐卡复核

交付前逐张检查：

- 仅凭标注来源，能否支持标准答案？
- 是否只有一个明确回忆目标？
- 脱离原页后题干是否成立？
- 是否有歧义、答案提示或不必要的阅读负担？
- 答案是否简洁且保留必要条件？
- 数字、单位、符号、否定和例外是否准确？
- 图表是否正确理解？
- 是否与其他卡重复？
- 是否遗漏重要知识点？
- 不确定内容是否明确标出？

发现问题后修改、拆分、合并或暂缓，不能仅因为格式正确就保留。结构校验不能代替语义复核；Agent 可完成常规复核后继续导出，不需要额外设置用户批准环节。

## 十二、每张卡保留的信息

每张卡至少包含卡型、问题或填空正文、标准答案或填空目标、来源文件及页码、所属知识点；需要时添加补充解释。保留未覆盖或待核对事项，便于补充和修订。

导出时按 [schema](schema.md) 保存这些信息。生成 package 之后检查卡型、数量、媒体与来源字段；不能把成功写出文件等同于已在用户的 Anki 中完成导入。
